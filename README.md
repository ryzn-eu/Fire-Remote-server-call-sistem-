# Call System

## Sistema di supporto tra interfaccia e server Horizon Fire

> **Stato:** Beta dimostrativa / Sperimentale

Questo progetto rappresenta un sistema di supporto alla comunicazione tra l'interfaccia e i server di **Horizon Fire**, sviluppato a scopo dimostrativo durante la fase beta.

Il codice integra le prime versioni del nuovo linguaggio di scrittura informatica creato dal team Horizon, denominato **Horizon Code**. Si tratta di una nuova tipologia di codice progettata per gestire e strutturare il flusso dei dati tra l'interfaccia e i server della piattaforma.

### Horizon Code

Horizon Code utilizza una struttura di codice appositamente progettata per rendere il flusso dei dati difficilmente leggibile e interpretabile al di fuori dell'ambiente previsto.

I dati generati dal sistema possono apparire illeggibili o privi di significato quando vengono osservati direttamente. All'interno della piattaforma, tuttavia, un decoder integrato è in grado di interpretarli utilizzando specifiche strutture di decodifica.

Queste strutture sono progettate per essere utilizzate esclusivamente dal software Horizon e fanno parte del sistema sperimentale di gestione e interpretazione dei dati.

### Sicurezza

Il sistema è attualmente in fase **beta** e deve quindi essere considerato sperimentale.

L'implementazione non è ancora stata sottoposta a tutte le verifiche necessarie per un utilizzo in produzione. Di conseguenza, durante questa fase potrebbero essere presenti vulnerabilità, comportamenti imprevisti o problemi di sicurezza.

Per questo motivo, il progetto è destinato esclusivamente a:

- test di sviluppo;
- dimostrazioni;
- sperimentazione;
- test dell'infrastruttura;
- sviluppo delle funzionalità di Horizon Code.

### Hosting e dati

Durante la fase beta, la piattaforma viene utilizzata esclusivamente a scopo dimostrativo e di sviluppo.

I dati presenti nell'ambiente di test potranno essere successivamente trasferiti sull'infrastruttura di hosting definitiva una volta completata la fase di sviluppo.

**Si sconsiglia pertanto di utilizzare account o dati reali durante la fase beta.**

Fino al completamento dello sviluppo, il sistema deve essere considerato un ambiente sperimentale e potrebbe essere soggetto a modifiche, malfunzionamenti o possibili vulnerabilità.

---

> **Nota:** Horizon Code e il sistema di decodifica associato sono attualmente in fase sperimentale e non devono essere considerati un sistema di sicurezza definitivo.
